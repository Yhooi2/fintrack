# FinTrack — личный финансовый менеджер

Учебный full-stack проект, выполненный в рамках производственной (эксплуатационной)
практики по направлению 02.03.03 «Математическое обеспечение и администрирование
информационных систем», профиль «Разработка программного обеспечения (Full-stack
разработка)».

Приложение относится к области **финансовых технологий (fintech)**: оно помогает
пользователю вести учёт личных доходов и расходов, видеть текущий баланс и
аналитику по операциям.

## Возможности

- регистрация и авторизация пользователей (JWT, хэширование паролей через bcrypt);
- добавление, просмотр и удаление финансовых операций (доходы/расходы);
- категории операций;
- сводная аналитика: суммы доходов, расходов и итоговый баланс;
- фильтрация операций по периоду.

## Технологический стек

| Слой        | Технологии                                        |
|-------------|---------------------------------------------------|
| Backend     | Node.js, Express, better-sqlite3, JWT, bcryptjs   |
| База данных | SQLite                                            |
| Frontend    | HTML, CSS, JavaScript (Fetch API)                 |
| Безопасность| JWT-аутентификация, хэширование паролей, валидация входных данных |

## Запуск

```bash
cd backend
npm install
npm start
```

После запуска приложение доступно по адресу `http://localhost:3000`.

## Безопасность денежных сумм

Все суммы хранятся в базе как целое число копеек, что исключает ошибки
округления, характерные для чисел с плавающей точкой при работе с деньгами.
